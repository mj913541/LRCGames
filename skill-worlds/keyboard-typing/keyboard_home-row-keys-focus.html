📋 Teacher & Standards

🎓 Grade Level

Grades 1–3 (adaptable)

📚 Strand

Technology Skills — Keyboard Familiarity

🎯 Skill

Identify and locate the nine home-row letter keys on a Chromebook keyboard.

🌟 Learning Target

Students will place A, S, D, F, G, H, J, K, and L in the correct positions.

💬 I Can Statement

“I can find letters on a Chromebook keyboard and put them in the right places.”

📖 AASL Connection

Shared Foundation I — Inquire: applying prior knowledge and observation; Shared Foundation V — Explore: developing skills through practice. These are instructional connections, not quotations of indicators.

💻 ISTE Connection

1.1 Empowered Learner: using an interactive tool and feedback to build skills. 1.5 Computational Thinker: recognizing spatial patterns and correcting placement errors.

🔎 Assessment Evidence

  • Correctly places all nine home-row letters
  • Locates practiced letters on a physical Chromebook
  • Works independently or with appropriate support

🌈 Differentiation

Support: Compare with a physical keyboard, model one placement, or provide partner assistance.

On-Level: Place all nine keys independently.

Extension: Find the letters on a real keyboard and type a word using the practiced keys.
