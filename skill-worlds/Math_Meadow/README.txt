Math Meadow LRC Quest — separate pages

File convention: {skill-name}_{grade-levels}_{game-name}.html
Grade levels: prek-k means Pre-K through Kindergarten.

Open index.html in a browser. Keep games/, styles.css and app.js in the same relative locations.

Each game includes a Teacher & Parent button to show I Can statements and related ISTE, AASL and Kindergarten Common Core connections. Pre-K is not itself a Common Core grade level; the CCSS entries are Kindergarten connections.

Scores are temporary per browser tab session and can be emailed as a draft, not sent automatically.
